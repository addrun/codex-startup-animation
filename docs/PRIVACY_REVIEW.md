## 运行时的隐私边界

- 页面检测取得匹配目标窗口的画面，在本机内存中缩小并统计布局/边缘；画面可能含有页面内容，但不保存或上传目标窗口截图，也不做 OCR。
- 可访问性检测只请求控件类型、屏幕外状态和边界，不读取控件名称、输入值或聊天文字。
- 程序没有网络上传或遥测接口，也不读取聊天数据库、登录凭据或 Codex 全局状态文件。
- 本地日志可能包含项目路径、进程标识、时间和窗口几何。这些日志、登录项备份及测试输出默认由 Git 规则和发布清单排除，只有正式 MP4 进入仓库的 `output/`。

分享故障资料时仍应检查并去除本机身份信息，不要把整个正在运行的 `output/` 目录直接上传。

## 尚不能据此确认的内容

- 视频是抽帧检查，没有穷举每一帧；文本和二进制模式检测也不能识别所有形式的隐私信息。
- WAV 的元数据与来源记录已检查，但本轮没有独立听验或转写所有人声。现有制作记录将其描述为上游欢迎语混音，不以元数据正常来证明每句人声都没有个人内容。
- GitHub 账号名、noreply 邮箱中的公开账号信息、提交时间和项目偏好会随公开仓库被访问，这是公开署名与内容本身。
- 原启动项目、背景音和部分角色参考的公开分发权利尚未在现有记录中确认；对应说明保留在 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。本项目没有统一开源许可证。
